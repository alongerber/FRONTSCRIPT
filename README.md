# פרונט סטודיו

סטודיו הפקת וידאו פנימי. אתר אחד שמחליף את הריצה בין ChatGPT, ElevenLabs,
HeyGen ו-Gemini — ומרכיב את הסרטון עד קובץ MP4 אנכי מוכן להעלאה.

---

## איך זה עובד

שישה שלבים. כל אחד שומר את התוצר שלו, כך שכישלון בשלב מאוחר לא מחייב
לשלם שוב על השלבים שלפניו.

```
1  תסריט      מכונת ניסוחים            ~$0.30
2  קול        ElevenLabs                ~11¢ לטייק
3  B-roll     תמונות זולות → וידאו יקר  ~$2
4  אווטאר     HeyGen                    ~$2.7   ← השלב היקר
5  כתוביות    יישור לתסריט              ~0
6  עריכה      FFmpeg                    חינם
```

**העיקרון שמחזיק את כל המערכת:** רינדור אווטאר עולה פי 25 מטייק קול,
והנפשת B-roll עולה פי 100 מתמונה. לכן המערכת נועלת כל שלב יקר מאחורי
אישור של השלב הזול שלפניו — הקול חייב להישמע עד הסוף לפני שכפתור
האווטאר נפתח, והתמונה חייבת להיבחר לפני שאפשר לשלם על הנפשה.

### מכונת הניסוחים

שלב התסריט לא מציע לך טונים ולא קטגוריות. הוא מייצר **מילים**:

| כפתור | מה הוא מחזיר |
|---|---|
| צור תסריטים | שישה תסריטים מלאים, שונים במבנה ולא רק בניסוח |
| ↻ עוד שישה | שישה חדשים לגמרי — השרת זוכר מה כבר ראית ולא חוזר עליו |
| ↻ ניסוחים | שמונה ניסוחים חלופיים לשורה בודדת, בלי לגעת בשאר |
| 💥 פאנצ'ים | עשר שורות סיום חלופיות לסטאפ הקיים |
| ⚡ פתיחות | עשר שורות פתיחה — שלוש השניות שקובעות אם ממשיכים לצפות |
| 🎯 חדד לי | ארבע קריאות מחודדות של הכיוון שכתבת, כל אחת עם שורת דוגמה |

בכל אחד מהם אפשר להוסיף הוראה חופשית ("יותר קצר", "בלי המילה הזאת",
"שיסתיים בשאלה") לפני שמייצרים.

### הכתוביות

המערכת יודעת מה נאמר בסרטון כי היא כתבה את התסריט. לכן היא לא מנחשת
מילים — היא רק מחפשת **מתי** כל מילה נאמרה, ומלבישה על התזמון את האיות
מהתסריט. התוצאה: שמות לא משתבשים ואין מה לתקן ידנית.

### העריכה

ה-B-roll מחליף תמונה בלבד. פס הקול המקורי מועתק לקובץ הסופי בלי
לגעת בו (`-c:a copy`), כך שאין שום דרך שהסנכרון יישבר.

## התקנה מקומית

```bash
git clone <הכתובת של ה-repo>
cd FRONTSCRIPT

python3 -m venv .venv
source .venv/bin/activate          # ב-Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # ואז ערוך אותו, ראה למטה
uvicorn app.main:app --reload
```

פתח <http://127.0.0.1:8000>.

**FFmpeg חייב להיות מותקן:**

```bash
brew install ffmpeg                # מאק
sudo apt install ffmpeg            # לינוקס
winget install Gyan.FFmpeg         # ווינדוס
```

## המפתחות

ערוך את `.env`. **הקובץ הזה לעולם לא נכנס ל-Git.**

| משתנה | מאיפה משיגים | בלעדיו |
|---|---|---|
| `STUDIO_PASSWORD` | אתה בוחר | אי אפשר להיכנס |
| `SECRET_KEY` | `python3 -c "import secrets;print(secrets.token_hex(32))"` | הכניסה לא מאובטחת |
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) | אין מנוע תסריט |
| `ELEVENLABS_API_KEY` | elevenlabs.io → Profile → API Key | אין קול ואין כתוביות |
| `HEYGEN_API_KEY` | app.heygen.com → Settings → API | אין אווטאר |
| `FAL_KEY` | [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys) | אין יצירת B-roll |

מנוע שחסר לו מפתח מסומן באדום בראש המסך. שאר המערכת ממשיכה לעבוד —
אפשר למשל להעלות סרטון אווטאר מוכן ולדלג על HeyGen לגמרי.

## העלאה לאוויר

### Render (מומלץ — יש קובץ מוכן)

1. דחוף את ה-repo ל-GitHub.
2. ב-Render: **New → Blueprint**, בחר את ה-repo. `render.yaml` יוגדר לבד.
3. בלוח ההגדרות מלא את חמשת המפתחות (`SECRET_KEY` נוצר אוטומטית).
4. חבר דומיין תחת **Settings → Custom Domain**.

המסלול `starter` עולה בערך $7 לחודש. הוא נרדם אחרי חוסר פעילות ולוקח לו
כ-30 שניות להתעורר בפעם הראשונה ביום — אם זה מפריע, שדרג ל-`standard`.

> **הדיסק הקבוע הוא לא אופציונלי.** `render.yaml` מגדיר דיסק ב-`/var/data`
> ומצביע אליו את `MEDIA_ROOT`. בלעדיו כל הפרויקטים והקבצים נמחקים בכל
> פריסה מחדש.

### כל מקום אחר עם Docker

```bash
docker build -t front-studio .
docker run -p 8000:8000 --env-file .env -v $(pwd)/media:/var/data front-studio
```

ה-Dockerfile כבר כולל FFmpeg ופונטים עבריים — אין מה להתקין בנפרד.

## דברים שכדאי לדעת

**עברית ומודלים.** `eleven_v3` הוא החדש והמשחקי, אבל בעברית הוא לפעמים
שם דגשים במקומות מוזרים. `eleven_multilingual_v2` ותיק יותר ולעיתים
קרובות נקי יותר. כפתור **⚖ השווה מודלים** מפיק את שניהם על אותו טקסט —
תשמע ותחליט בעצמך במקום להאמין לברירת מחדל.

**נעילת תוצאה.** שדה ה-seed בשלב הקול מחזיר בדיוק אותה הקראה. כשמצאת
טייק טוב — רשום את המספר.

**מזהי מודלים ב-fal.ai משתנים.** אם ייצור תמונה או וידאו מחזיר 404,
המודל כנראה שונה. הרשימה מוגדרת בראש `app/engines/broll.py` — בדוק ב-
[fal.ai/models](https://fal.ai/models) ועדכן את המזהה.

**עבודות ארוכות שורדות סגירת לשונית.** רינדור HeyGen לוקח 2–10 דקות
ורץ בשרת. אפשר לסגור את הדפדפן ולחזור — הפס ימשיך מאיפה שהיה. מה שלא
שורד זו הפעלה מחדש של השרת עצמו: עבודות שרצות באותו רגע יאבדו, אבל
כל מה שכבר נשמר לדיסק נשאר.

**גודל העלאה** מוגבל ל-512MB לקובץ.
